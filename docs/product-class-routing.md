# Product-class routing for ad briefs

Updated 2026-10-21. Choose the relevant buying situation. This is not a product-launch plan or a replacement for actual product facts.

| Class | Primary desire to consider | Required proof | Common mistake |
|---|---|---|---|
| Comic/art book | Read, keep, revisit, share, collect | Actual readable pages plus physical/use context | A free gag and an interchangeable cover |
| Member publication | Receive a worthwhile next installment | Actual current artifact and truthful recurring promise | Static archive sold as endless new value |
| Patronage | Sustain this particular artist/work | Honest support purpose and continuing authored work | Guilt or fabricated personal access |
| Collectible/random cards | Discovery and collecting | Real opening, art/texture, exact guaranteed contents | Invented rarity, jackpot or resale value |
| Game kit | Enjoy playing together | Legal decision/consequence; required components | Unboxing presented as proof of gameplay |
| Original/limited object | Possess authored work | Material, provenance, size and real availability | Artificial scarcity or investment claims |
| Apparel | Wear a design that fits taste/body | Real sample, on-body fit and fabric details | A mockup sold as quality proof |
| Lamp/furniture | Live with it and use it | Actual room/scale/function and specs | Beautiful render conceals impractical use |
| Maker/robotics kit | Build/control something satisfying | Real outcome, included parts and skill/setup limits | Finished demo implies effortless assembly |
| Finished technical hardware | Obtain a useful capability | Real task, measured limits and compatibility | Aspirational sci-fi stands in for performance |
| Software/tool | Get a task done better | Real input/output, environment and license | Fake UI or unmeasured hours-saved claim |
| Recurring software/service | Keep receiving useful ongoing capability | Repeat use, support/update/operation scope | Subscription exists only to create MRR |
| Gift/bundle | Choose something right for someone/situation | Recipient fit, coherent contents and fulfillment | Random extras or undisclosed duplicates |
| B2B implementation | Remove costly work/risk | Baseline, scoped result and acceptance evidence | Entertainment with no business problem |

A book can belong to reading, collecting and gifting simultaneously, but one creative should have a legible main job. Physical products are not divided into 'aura' and 'not aura': meaning and practical use can reinforce each other.

For Comics, preserve authentic hand-drawn work, brand voice and face rules. For Labs engineering, demonstrate real capability and explicitly distinguish concept, prototype and shipping product. Shared ownership does not justify mixing promises or fabricating product readiness.
